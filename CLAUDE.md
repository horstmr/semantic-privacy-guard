# CLAUDE.md

Este repositório tem **dois trabalhos independentes** convivendo. Identifique
qual deles a tarefa toca antes de agir.

## 1. Código — `semantic-privacy-guard`

Projeto Java (Maven, `pom.xml`, `src/`). É o propósito original do repositório.
Convenções em `CONTRIBUTING.md`, `SECURITY.md` e `PUBLISHING.md`.

## 2. Portfólio de traduções — `portfolio/`

Não tem relação com o código. Extração e organização do histórico de trabalhos
de tradução do usuário a partir das contas de e-mail.

**Antes de qualquer tarefa que envolva `portfolio/`, leia `portfolio/CONTEXTO.md`.**
Ele traz o estado dos dados, as queries do Gmail que isolam trabalhos concluídos
em cada agência, as limitações do conector e as pendências em ordem de retorno.

Índice:

| Arquivo | Conteúdo |
|---|---|
| `portfolio/CONTEXTO.md` | Transferência de contexto entre sessões — **comece aqui** |
| `portfolio/CONSOLIDADO.md` | Visão unificada das duas contas de e-mail |
| `portfolio/ANALISE-PERIODO-COMPLETO.md` | Varredura 2019–2026 (quadro correto) |
| `portfolio/PORTFOLIO.md` | Portfólio por agência (escopo 2023–2026) |
| `portfolio/TOTAIS-PALAVRAS-E-VALORES.md` | Volumes, tarifas, valores pagos |

Regra de método definida pelo usuário: para dizer se um trabalho foi feito,
usar evidência documental do e-mail — nunca presumir.
